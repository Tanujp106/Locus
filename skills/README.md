# Locus skills

These skills are reusable behavior imported from the current global Codex skill collection.

- `emil-design-eng`: UI polish and design-engineering quality
- `animation-vocabulary`: name vague motion effects precisely
- `review-animations`: review motion code against a high craft bar
- `apple-design`: fluid, physical, gesture-driven interface principles
- `improve-animations`: produce prioritized motion-improvement plans

The official `lean-ctx` integration remains installed and managed by LeanCTX rather than being vendored here.

The Incog repositories currently provide reusable agent instructions but no standalone `SKILL.md` files. Songrec currently has no repository-local `SKILL.md` or `AGENTS.md`; its repeated debugging knowledge should be promoted into a dedicated skill only after it has been reviewed and generalized.
