# Locus

Skills and plugins for automating mundane design processes.

## Organization

Skills are grouped by capability:

- `skills/design/` — design and interface workflow skills.
- `skills/development/` — implementation and engineering workflow skills.
- `skills/tools/` — integrations and utility workflow skills.

Add each skill at:

```text
skills/<category>/<skill-name>/SKILL.md
```

Keep the skill directory name aligned with the `name` in its frontmatter.
