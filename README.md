# Locus

Skills and plugins for automating mundane design processes.

## Organization

Skills are grouped by workflow:

- `skills/exploration/` — research, reference-finding, and design-direction exploration.
- `skills/process/tuning/` — focused parameter-tuning workflows such as DialKit.
- `skills/development/` — implementation and engineering workflows.
- `skills/tools/` — integrations and utility workflows.

Add each skill at:

```text
skills/<workflow>/<skill-name>/SKILL.md
```

Keep the skill directory name aligned with the `name` in its frontmatter.
